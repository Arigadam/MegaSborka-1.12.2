# MegaSborka 1.12.2
Индустриальная сборка со случайными модами!
Чтобы скачать перейдите в Releases и скачайте ZIP архив или файл .mrpack (рекомендуется) и кидайте его в Ваш лаунчер.
Если ваш лаунчер не подерживает сборки из MultiMC также скачайте ZIP архив. Далее удалите папку mods и config и перетащите всё из папки .minecraft из архива в вашую папку .minecraft с заменой. Далее запустите в вашем лаунчере версию Forge 1.12.2.
